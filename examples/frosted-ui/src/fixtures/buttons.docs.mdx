{/\*
An MDX **documentation page** — SPEC §14.

The difference between this file and `mdx-notes.fixture.mdx` sitting beside it
is one suffix and nothing else in the machinery: `.docs.mdx` is globbed,
indexed, selected and rendered by exactly the same path a fixture takes, and
is one fixture for the same reason (prose has no named states). What the
suffix buys is the ability to say which is which — the tree marks this row
"Doc" — without a second pipeline, a second glob map or a second renderer.

That is also the boundary being demonstrated. uaight is not a documentation
framework (§1.4): there is no router here, no authored navigation and no page
hierarchy apart from the fixture tree. A docs page is prose that lives next to
the components it is about, which is the one thing a component explorer is
actually in a position to offer.
\*/}
